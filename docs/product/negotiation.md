# Negotiation

See [../../NERVENET_PRODUCT_SPEC.md](../../NERVENET_PRODUCT_SPEC.md), especially section 16.

Negotiation is planned as structured coordination among agents such as Shipment, Carrier, and Warehouse agents. Each participant may have goals, constraints, beliefs, capabilities, and risk preferences.

Negotiation must be machine-verifiable. Messages should be schema-bound, auditable, permissioned, and tied to explicit commitment semantics. It should not be implemented as unrestricted LLM conversation.
