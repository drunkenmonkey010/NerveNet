# Product Specification Reference

The canonical product specification is [../../NERVENET_PRODUCT_SPEC.md](../../NERVENET_PRODUCT_SPEC.md).

This document exists as the product documentation entry point under `docs/product`. Detailed product documents in this directory must remain consistent with the canonical specification and should link back to it when proposing changes.

Current implementation status:

- Implemented: FastAPI service foundation, PostgreSQL configuration, Alembic migrations, Organization model, Organization API, health check, tests.
- Specified but not implemented: agent intelligence, beliefs, memory, negotiation, ML models, digital twin, blockchain network, reputation algorithms.
