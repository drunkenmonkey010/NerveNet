# ML Architecture

See [../../NERVENET_PRODUCT_SPEC.md](../../NERVENET_PRODUCT_SPEC.md), especially sections 13 and 14.

Planned models include ETA prediction, SLA breach prediction, route risk prediction, demand forecasting, anomaly detection, agent reliability prediction, interaction outcome prediction, belief update modeling, and counterfactual outcome prediction.

Each model requires a defined problem, dataset, validation process, baseline, feature set, training process, evaluation metrics, versioning, deployment role, monitoring, and retraining criteria.

No ML model is currently implemented. Early product work should prefer measurable baselines over premature complexity.
